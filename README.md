# Order Food - Web Demo Đặt Món Ăn

Trang web đặt món ăn đơn giản, giao diện hiện đại viết bằng HTML, CSS và JavaScript thuần (Vanilla JS).

## ✨ Tính năng
- Hiển thị danh mục món ăn (Món chính, Ăn vặt / Fast food, Đồ uống).
- Lọc theo danh mục.
- Giỏ hàng động: Thêm món, tăng/giảm số lượng, tính tổng tiền tự động.
- Modal xác nhận đặt hàng thành công.
- Giao diện responsive trên cả điện thoại và máy tính.

## 🚀 Cách mở và chạy thử
1. Mở trực tiếp file `index.html` bằng trình duyệt bất kỳ (Chrome, Safari, Edge, Firefox).
2. Hoặc chạy server tĩnh nhanh bằng Python trong terminal:
   ```bash
   python3 -m http.server 3000
   ```
   Sau đó truy cập `http://localhost:3000`.
